## Restrições importantes

Esta é uma **prévia não aprovada pela clínica**. Por isso, o HTML inclui `noindex, nofollow` e uma faixa indicativa de projeto demonstrativo. Não foram inventados WhatsApp, CREFITO, formações/especializações, depoimentos, avaliações, procedimentos, horários ou lista de convênios. O contato usa telefone fixo via `tel:`, sem criar um WhatsApp fictício.

As fotografias e a marca devem ser utilizadas apenas no contexto desta proposta comercial e após autorização da clínica para a versão definitiva. Referências originais arquivadas no Google Drive da Guará, pasta `A GUARÁ/FisioCentro Erechim — preview/01 — Referências originais`.

## Publicação

Para GitHub Pages, habilitar **Settings → Pages → Deploy from a branch → main / (root)** e manter os arquivos desta pasta na raiz do repositório. Não publicar sem todos os arquivos em `assets/images/`.
